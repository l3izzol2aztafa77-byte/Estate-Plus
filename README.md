# Estate Plus

ต้นแบบเว็บแพลตฟอร์มอสังหาริมทรัพย์ครบวงจร (Module 02–05): ซื้อ ขาย เช่า ขายฝาก ลงทุน และตลาดบริการบ้าน
รองรับภาษาไทย/อังกฤษ ใช้งานได้ทั้งคอมพิวเตอร์และมือถือ

> **สถานะ:** Prototype ฝั่งหน้าบ้าน (Frontend) เท่านั้น ข้อมูลทั้งหมดเก็บในหน่วยความจำของเบราว์เซอร์ รีเฟรชหน้าแล้วข้อมูลที่กรอกจะหายไป ยังไม่มี Backend, ฐานข้อมูล หรือการเชื่อมต่อระบบชำระเงินและ e-KYC จริง

## ฟีเจอร์หลัก

| ส่วน | รายละเอียด |
|---|---|
| ซื้อ / เช่า / ขายฝาก | ค้นหา กรองประกาศ หน้ารายละเอียด ติดต่อเจ้าของ |
| นักลงทุน | รายการทรัพย์ขายฝาก เครื่องคำนวณผลตอบแทน |
| บริการบ้าน | ขอใบเสนอราคา ติดตามงาน ชำระเงิน |
| สมัครสมาชิก | ยืนยันเบอร์ (OTP) และอีเมล, สมัครเป็นผู้ให้บริการ (บุคคล/นิติบุคคล) |
| ยืนยันตัวตน (KYC) | 4 ขั้น: ข้อกำหนดและความยินยอม → บัตรประชาชน → เซลฟี่ → ตรวจสอบ, หน้า “ความยินยอมของฉัน” พร้อมบันทึกเวอร์ชันและเวลา, ถอนความยินยอมได้ |
| ลงประกาศบริการ | สำหรับผู้ให้บริการ: เลือกบริการบ้านและสวนได้ 107 รายการใน 13 หมวด พร้อมรายละเอียดและราคาต่อบริการ |
| ศูนย์ช่วยเหลือ | FAQ 24 ข้อ 7 หมวด ค้นหาได้ พร้อมช่องทางติดต่อ Email / โทรศัพท์ |
| แดชบอร์ด | ประกาศของฉัน บิล การชำระเงิน สินเชื่อ ความปลอดภัย |
| หลังบ้าน (Admin) | ผู้ใช้ อนุมัติ KYC ประกาศ งานบริการ การชำระเงิน บัญชี สิทธิ์ตามบทบาท |

## โครงสร้างไฟล์

```
estate-plus/
├── index.html              หน้าเว็บและโค้ดทั้งหมดของแอป (template + logic + ข้อความ TH/EN)
├── assets/
│   ├── js/
│   │   ├── react.production.min.js
│   │   ├── react-dom.production.min.js
│   │   ├── dc-runtime.js    ตัวแสดงผล template ของต้นแบบ
│   │   └── th-geo.js        ข้อมูลจังหวัด/อำเภอ (kongvut/thai-province-data, MIT)
│   ├── img/                 รูปตัวอย่างอสังหาฯ (.webp)
│   └── fonts/               Anuphan, IBM Plex Sans Thai (.woff2)
├── .nojekyll
└── README.md
```

## เปิดดูในเครื่อง

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย หรือรันเว็บเซิร์ฟเวอร์ง่าย ๆ:

```bash
cd estate-plus
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวม `.nojekyll`) ไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ที่ **Source** เลือก **Deploy from a branch** → Branch `main` → โฟลเดอร์ `/ (root)` → **Save**
5. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ `https://<username>.github.io/<repository>/`

ถ้าอัปโหลดผ่านหน้าเว็บ GitHub: กด **Add file → Upload files** แล้วลากทั้งโฟลเดอร์ `assets` และไฟล์อื่น ๆ ลงไป (ไฟล์ `.nojekyll` เป็นไฟล์ซ่อน บาง OS ต้องเปิดการแสดงไฟล์ซ่อนก่อนจึงจะลากได้)

## ค่าที่ต้องแก้ก่อนใช้งานจริง

| รายการ | ตำแหน่งใน `index.html` | ค่าปัจจุบัน |
|---|---|---|
| อีเมลและเบอร์ติดต่อ | ค้นหา `const CONTACT` | `support@estateplus.example`, `02-000-0000` (ค่าชั่วคราว) |
| เวลาทำการ | ค้นหา `ctHours` | จันทร์–ศุกร์ 09:00–18:00 น. |
| ข้อกำหนดการใช้งาน / นโยบายความเป็นส่วนตัว / ความยินยอมข้อมูลใบหน้า | ค้นหา `docs: {` | ฉบับร่างสำหรับต้นแบบ ต้องให้ฝ่ายกฎหมายตรวจก่อนใช้จริง |
| เวอร์ชันเอกสาร | ค้นหา `const DOC_VER` | 1.0 |

## ข้อจำกัดของต้นแบบ

- การถ่ายเซลฟี่และตรวจบัตรประชาชนเป็นการจำลอง ยังไม่ได้เชื่อมผู้ให้บริการ e-KYC
- การชำระเงินเป็นการจำลอง ยังไม่ได้เชื่อม Payment Gateway
- OTP และอีเมลยืนยันเป็นการจำลอง
- ไม่มีการบันทึกข้อมูลถาวร
